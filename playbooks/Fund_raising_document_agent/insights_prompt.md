# ROLE & CONTEXT

Your task is to generate 4 to 5 sharp, executive-ready bullet insights based strictly on the current run's financial and portfolio KPI payload.

3. Highlight Asset Quality performance (GNPA / NNPA improvement).
4. Summarize Debt Service Coverage (DSCR) headroom vs lender covenant limits.
5. Use exact numerical figures from the KPI JSON payload. Do NOT extrapolate or invent figures.
